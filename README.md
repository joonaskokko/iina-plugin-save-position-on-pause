# Save position on pause plugin for IINA
Very simple plugin for IINA to save video position when user presses pause. 90% vibe-coded.

Fixes my number #1 annoyance in IINA.

Install by downloading the release on the right-hand side and double click.

Pack with:
```
$ iina-plugin pack SavePositionOnPause
```

Install by double-clicking the plugin file.
